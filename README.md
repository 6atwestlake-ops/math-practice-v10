# Math Practice

Offline-first daily math practice PWA for Cole (grade 9) and Taya (grade 6), plus a Dad dashboard.

## Install (iPhone)

1. Open the GitHub Pages site in **Safari**.
2. Tap **Share → Add to Home Screen**.

## Profiles

- **Cole** — Set 1 mix (~50 questions)
- **Taya** — grade 6 easier mix (~30 questions)
- **Dad** — dashboard of local + optional remote progress

Each student profile can set an optional 4-digit PIN (stored as a hash on the device).

## Optional sync

Leave `js/config.js` `endpointUrl` empty to keep sync off. After Apps Script deploy, paste the web-app URL there.
